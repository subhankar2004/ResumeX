# ResumeX — Frontend

Next.js 14 (App Router) frontend for ResumeX: marketing pages, auth, dashboard, the Rex chat, the template gallery and the LaTeX editor.

It runs as the `frontend` service in the root `docker-compose.yml` and calls the backend API at `NEXT_PUBLIC_API_URL` (default `http://localhost:4000/api`).

See the [root README](../README.md) for setup, architecture and development notes.
